# Social sharing fonts

The social image bundles static TrueType fonts so rendering does not need a font service at runtime.

- Fredoka Bold (700): https://fonts.google.com/specimen/Fredoka
- Nunito SemiBold (600): https://fonts.google.com/specimen/Nunito

Downloaded from the Google Fonts CSS API with `family=Fredoka:700|Nunito:600`.
Both fonts are distributed under the SIL Open Font License 1.1; the corresponding full licences are included alongside the fonts.
